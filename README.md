# 🛡️ Site Main Control — 다인에듀 사이트 관리 콘솔

`yalli2` GitHub에 올린 모든 학습 사이트를 **한 화면에서 관리**하고, **사이트마다 누가 들어올 수 있는지**를 회원별로 정하는 마스터 사이트입니다.

**콘솔 주소:** https://yalli2.github.io/site_main_control/

## 주요 기능

| 메뉴 | 할 수 있는 일 |
|---|---|
| 📊 대시보드 | 사이트·보호·가드·회원 현황, 14일 접속 추이, 인기 사이트, 대기 요청, 만료 임박 회원, 최근 거부 접속(바로 허용) |
| 🌐 사이트 | GitHub 저장소 자동 목록, 카테고리·모드·가드 필터, 즐겨찾기, 일괄 모드 변경, **가드 원클릭 설치/제거**, 접속 상태 점검, 링크·QR·학생 안내문 복사, 공개 기간(시작·종료일) 예약 |
| 👤 회원 | 이메일로 등록, 엑셀 붙여넣기 일괄 등록, 그룹·개별 사이트 권한, 만료일(+1개월 버튼), 정지/재개, CSV 내보내기 |
| 🧩 그룹(반) | 반 단위로 사이트 묶기 → 학생을 그룹에 넣기만 하면 권한 완성, 그룹 만료일, 링크 모음 복사 |
| 📨 접근 요청 | 권한 없는 학생이 사이트에서 보낸 요청을 한 번에 승인(개별/그룹) 또는 거절 |
| 📜 접속 기록 | 허용·거부·방문 기록 검색, CSV 내보내기, 오래된 기록 정리 |
| ⚙️ 설치·설정 | 단계별 설치 안내, Firebase 설정 저장, 보안 규칙 생성, GitHub 토큰, 백업·복원 |

### 접속 모드 5가지
- 🌐 **공개** — 누구나 (로그인 없음)
- 👥 **회원 전체** — 등록된 활성 회원 누구나
- 🔒 **지정 회원만** — 권한을 준 회원·그룹만
- 🛠️ **점검 중** — 관리자만, 안내문 표시
- ⛔ **차단** — 관리자 외 접속 불가

## 작동 방식

```
학생 → yalli2.github.io/저장소  ──(guard.js 한 줄)──▶  Firebase (로그인 + 권한 확인 + 기록)
                                                         ▲
관리자 → site_main_control 콘솔 ─────────────────────────┘
```

- 각 사이트 `<head>`에 아래 한 줄이 들어갑니다. 콘솔에서 버튼으로 자동 설치할 수 있어요.
  ```html
  <script src="https://yalli2.github.io/site_main_control/guard.js" data-site="저장소이름"></script>
  ```
- 모든 사이트가 같은 주소(`yalli2.github.io`)라서 **한 번 로그인하면 모든 사이트를 통과**합니다.
- `config.js`가 비어 있거나 사이트 모드가 ‘공개’면 가드는 아무것도 막지 않습니다(안전한 기본값).
- Google 로그인 + 이메일/비밀번호(인증 메일) 지원, 카카오톡 인앱 브라우저 감지 시 ‘외부 브라우저로 열기’ 안내.

## 처음 설치 (약 10분)

1. **GitHub Pages 켜기**: 이 저장소 Settings → Pages → Branch `main` / `(root)` → Save
2. **Firebase 프로젝트** 만들기 → 웹 앱 등록 → `firebaseConfig` 복사
3. Authentication에서 **Google**, **이메일/비밀번호** 사용 설정 → 승인된 도메인에 `yalli2.github.io` 추가
4. **Firestore Database** 만들기 (서울 리전, 프로덕션 모드)
5. 콘솔 [설치·설정]에 `firebaseConfig`와 관리자 이메일 입력 → **GitHub 토큰** 등록 후 [config.js에 저장]
6. [설치·설정] ③의 **보안 규칙**을 Firestore 규칙 탭에 붙여 넣고 게시 (`firestore.rules` 파일과 같은 내용, 관리자 이메일만 다름)
7. 상단 [관리자 로그인] → [사이트]에서 가드 설치 → 모드 지정

자세한 단계는 콘솔의 [설치·설정] 화면에 링크와 함께 나와 있어요.

## 🎙 말하기 연습 · 반 · 리그 (speak.js)

가드(`guard.js`)가 설치된 **모든 어학 사이트**에 오른쪽 **🎙 말하기** 버튼이 자동으로 생겨요. (어학 사이트가 아니면 나타나지 않아요.)

| 기능 | 내용 |
|---|---|
| 🔊 듣기 | 사이트 언어의 원어민 음성(브라우저 음성), 천천히 듣기, 음성 선택 |
| 🎯 문장 고르기 | 화면에서 문장 누르기 · 드래그 선택 · 이 페이지 문장 목록 · 사이트에서 🔊 들은 문장 · 직접 입력 |
| 🎙 말하기 평가 | 음성 인식으로 **정확도·완성도·유창성** 점수, 틀린 단어 표시 (Chrome·Edge 권장) |
| ⏺ 녹음 | 말하는 동안 자동 녹음 → 원어민→나 비교 듣기, 다운로드. **기기에만 저장**(최근 300개) |
| 🎙 문장마다 버튼 | **스페인어 사이트**: 화면의 문장 끝과 🔊 버튼 옆마다 작은 🎙 버튼 → 누르면 바로 녹음·평가하고 그 자리에 결과 카드(점수·틀린 단어·내 녹음·원어민 비교·저장). 버튼에 최고 점수 표시 |
| 🧠 AI 채점 | 브라우저 음성 인식이 아무것도 못 들으면(녹음과 마이크 충돌, 카카오톡 인앱, Firefox 등) **녹음 파일을 AI(Whisper)가 받아 적어 채점**. 처음 한 번 모델 다운로드(PC 약 75MB·휴대폰 약 40MB), 이후 캐시 |
| ⭐ XP·레벨·배지 | 점수별 XP, 연속 학습, 배지 14종 |
| 👥 우리 반 | **로그인 없이** 이름 + 방 코드로 입장(travel_spanish 방식, 실시간 MQTT). 반 순위(전체·사이트별)·실시간 피드·문장별 1등·인기 문장, `?room=코드` 링크·QR, 📺 크게 보기, 선생님 방 초기화. 같은 방 코드는 모든 어학 사이트에서 공유 |
| 🏆 리그 | 모든 어학 사이트 합산 전체 리그(주간·누적·언어별), 브론즈~다이아 티어 |

- 언어 자동 인식: 스페인어·영어·중국어·일본어·프랑스어·러시아어·이탈리아어·아랍어·카탈루냐어·포르투갈어·라틴어(라틴어는 녹음 후 자기 평가)
- 프로젝터용 반 대시보드: [`room.html?room=코드`](https://yalli2.github.io/site_main_control/room.html)
- 선생님 안내·전체 리그: [`speak.html`](https://yalli2.github.io/site_main_control/speak.html)
- 끄기: 사이트의 가드 줄에 `data-speak="off"`, 전체 끄기는 `config.js`의 `options.speak: false`
- 문장마다 🎙 버튼: 기본은 스페인어 사이트만. 사이트별로 가드 줄에 `data-speak-inline="off"`(끄기) 또는 `"on"`(켜기), 전체 언어 지정은 `config.js`의 `options.speakInline: ['es','fr', …]` (끄기 `false`)
- 문장 버튼은 제목·메뉴·단어 나열·빈칸 문제·✗ 틀린 예문·퀴즈 보기에는 붙지 않아요. 탭을 바꾸거나 내용이 새로 나타나면 자동으로 다시 붙어요
- AI 채점이 안 되면 학교 방화벽이 `cdn.jsdelivr.net`, `huggingface.co`를 막고 있는지 확인하세요 (그때는 녹음 듣고 스스로 별점 평가)
- 언어 지정: 가드 줄에 `data-speak-lang="es"` 처럼 지정 (자동 인식이 틀릴 때)
- 🏆 전체 리그(로그인)는 Firestore `speak_users`를 써요 — 보안 규칙을 다시 게시해야 작동해요. 👥 우리 반은 규칙 없이 바로 작동해요.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 관리 콘솔 (단일 파일) |
| `guard.js` | 각 사이트에 넣는 접속 확인 스크립트 |
| `config.js` | Firebase 연결 정보·관리자 이메일·옵션 (콘솔이 자동 생성) |
| `catalog.js` | 저장소별 한글 표시 이름·카테고리 |
| `firestore.rules` | Firestore 보안 규칙 템플릿 |
| `speak.js` | 🎙 말하기 연습 모듈 (가드가 어학 사이트에 자동으로 불러옴) |
| `speak.html` | 🎙 말하기 리그 · 반 관리 (선생님용) |

## 알아 두세요
- 공개 저장소의 원본 파일은 GitHub 저장소 페이지에서 누구나 볼 수 있습니다. 가드는 **사이트 화면 접속**을 관리합니다. 완전한 비밀이 필요한 자료는 저장소를 비공개로 두세요.
- GitHub 토큰은 콘솔을 연 브라우저의 localStorage에만 저장되고 GitHub API로만 전송됩니다.
- Firebase 무료(Spark) 한도: 하루 읽기 5만·쓰기 2만 회 — 수업용으로 충분합니다.
